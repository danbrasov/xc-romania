# XC România 🇷🇴

Clasament independent pentru zborurile XC cu parapanta din România.

## Prima versiune
- clasament General
- CCC / EN-D / EN-C / EN-B / EN-A
- Feminin, Tandem, Cluburi, 100 km+
- responsive pentru telefon
- structură pregătită pentru import automat și backend Cloudflare

Momentan interfața folosește date demonstrative. Următorul pas este conectarea sursei de date și calcularea clasamentului din zborurile reale.

XC România este un proiect independent și nu este afiliat XContest.
